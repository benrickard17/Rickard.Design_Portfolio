Each folder holds one file called index.html. That is what gives the clean addresses.
Every file name must stay exactly as it is.

HOW TO UPLOAD (GitHub website)
  1. Open the repository for jhlaserservices.co.uk on github.com.
  2. Click "Add file" > "Upload files".
  3. Drag in EVERYTHING inside this folder (the files and the folders), not the folder itself.
     The new index.html replaces the holding page. Don't delete CNAME.
  4. Click "Commit changes". The site updates in about 1-2 minutes.
  5. Check a few pages, e.g. jhlaserservices.co.uk/prices/ and jhlaserservices.co.uk/test
     (the second should show the 404 page).

AFTER IT'S LIVE
  Google Search Console > Sitemaps > enter "sitemap.xml" > Submit.
